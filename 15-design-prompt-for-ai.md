# Master Design Prompt

Design a premium civic-information platform.

Keywords:
Editorial, trustworthy, institutional, clean, minimal, premium.

Must feel like:
- Reuters
- Apple documentation
- GOV.UK
- Stripe documentation

Must NOT feel like:
- Gaming UI
- Cyberpunk
- Neon
- Hacker aesthetic
- Random protest poster

Use:
Large whitespace
Professional typography
Consistent spacing
Muted palette
Elegant cards
Evidence-first layouts
Responsive-first
Accessibility-first
