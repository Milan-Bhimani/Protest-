# Protest-

Protest- is a civic awareness platform with a Next.js frontend and supporting backend documentation for a production-ready student awareness experience.

## What’s in this repository

- `frontend/` — Next.js app for the public-facing experience
- Planning and product documentation for the platform

## Frontend

The frontend is built with:

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

### Run locally

```bash
cd frontend
npm install
npm run dev
```

### Environment variables

If your backend is not running on the default local URL, create `frontend/.env.local`:

```bash
NEXT_PUBLIC_API_URL=http://localhost:8000
```

### Build

```bash
cd frontend
npm run build
```

## Deployment

The frontend is configured for Vercel deployment.
